### MEU BLOG

Desenvolvi este blog fictício, para praticar os meus conhecimentos obtidos no curso técnico em desenvovimento em sistemas.

Utiliezei os conceitos de lógica de programação com a linguagem PHP, uso de variáveis, constantes, arrays, loops, estruturas de decisão, estruturas de comparação, funções e entre outras coisas.

Salvei os dados no banco de dados MYSQL, usando dos paramentros de consulta e de inserção no banco de dados.

Tecnologias: HTML,W3CSS, PHP E MYSQL.
